Historias de usuario

Requerimientos redactados desde la perspectiva de cada actor: qué quiere lograr y para qué. Usá los filtros para verlas por perfil.

MédicoHU-01

Como Médico, quiero poder ver los turnos agendados a mí para saber qué pacientes voy a tener que atender y en qué momento.

RecepcionistaHU-02

Como Recepcionista, quiero poder ver todos los turnos para saber qué franjas están disponibles.

PacienteHU-03

Como Paciente, quiero ver mis turnos para saber cuándo debo ir a la clínica.

PacienteHU-04

Como Paciente, quiero poder sacar un nuevo turno para acordar una fecha y médico para ir a la clínica.

PacienteHU-05

Como Paciente, quiero poder cancelar un turno para hacer saber que no voy a poder ir a la clínica.

MédicoHU-06

Como Médico, quiero establecer mis horarios para disponerlos para agendar turnos.

MédicoHU-07

Como Médico, quiero poder cancelar horarios para mostrar que no voy a estar disponible.

PacienteHU-08

Como Paciente, quiero recibir una notificación para saber que se canceló un turno mío.

RecepcionistaHU-09

Como Recepcionista, quiero poder ver qué pacientes recibieron notificaciones de turnos cancelados para poder notificar por teléfono a aquellos que no fueron notificados.

MédicoHU-10

Como Médico, quiero disponer horarios de sobreturno para que pacientes con turnos cancelados y/o urgentes puedan anotarse.

MédicoHU-11

Como Médico, quiero poder establecer un turno como urgente para que se priorice dentro del sistema lo antes posible.

PacienteHU-12

Como Paciente, quiero poder sacar un sobreturno para poder tener un turno después de que se cancele otro o por urgencias.

RecepcionistaHU-13

Como Recepcionista, quiero poder ver los datos de contacto de un paciente para contactarlo y notificarlo de un turno cancelado.

PacienteHU-14

Como Paciente, quiero cargar mis datos de contacto para poder ser contactado en caso de necesidad.

PacienteHU-15

Como Paciente, quiero poder contactarme con la clínica para reservar turnos.

Distribución: 7 historias de Paciente · 5 de Médico · 3 de Recepcionista. El siguiente paso del TP es desglosar estas historias en casos de uso.

El proyecto

App Clínica de Barrio — sistema de gestión de turnos para digitalizar y centralizar la atención de una clínica de barrio.
